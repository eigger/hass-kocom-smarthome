# Integration icon

`icon.png` (256 x 256) and `icon@2x.png` (512 x 512) are original generic wallpad energy-meter illustrations created for this repository on 2026-10-22 and distributed under its MIT License. They do not use the KOCOM logo or claim to be official manufacturer artwork.

The icon represents the supported wallpad energy-metering function. Local brand display requires Home Assistant 2026.3 or later; the integration retains its minimum Home Assistant 2025.8.0 support.
